# CAISSA

A free, cross-platform chess coaching and competition app.

## Design foundation

The premium visual system is documented in [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md), with centralized TypeScript tokens in `src/theme/tokens.ts`.

## Product direction

- Competitive 1v1 chess with a separate ranked ladder.
- Coach personalities for lessons, guidance, and engine-powered bot opponents.
- Post-game review with move-by-move engine analysis.
- Cross-platform experience for mobile, tablet, web, and desktop.

See [AGENTS.md](./AGENTS.md) for implementation and quality requirements.
